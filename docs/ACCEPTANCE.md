# iPhone 验收清单

当前构建只保证 CI 检查和编译，不代表以下真机步骤已经执行。准备一部 iOS 17+ iPhone，安装自行签名的 IPA，在系统照片中事先保留几张便于辨认的旧测试照片。

## 核心隐私场景

- 首次打开允许相机，照片选择「有限访问」。可以不选择任何旧照片。
- 尚未拍摄时点左下角：只出现本次空相册，旧照片不出现。
- 拍 A、B 两张：本次相册只有 A、B；稍后系统照片里也有 A、B。
- 编辑 A 的裁剪/旋转/曝光：系统照片中同一个 A 更新，记录数不增加，B 与旧照片不变。允许 iOS 的修改确认。
- 在系统照片使用恢复原图：能恢复 A 的原始内容。
- 打开借拍拍 C，切后台、锁屏再回来：仍显示 C，会话 ID 不变，系统照片仍保留 A、B、C。划掉应用重开后，预览为空。
- 开始拍摄后立即退到后台：晚到的本轮拍摄结果加入同一会话，返回仍可查看；进程重新启动后旧内容不恢复。
- 编辑页切后台再返回：保持当前照片和编辑状态；完成后的修改更新本会话照片及系统原记录。重启进程不恢复旧列表。
- 任务切换器显示「借拍 · 本次可见」遮罩，不能从预览截图读出照片。
- 原生权限提示、编辑确认和引导式访问浮层不会单独清空当前会话。

## 相机

- 前后摄像头切换、硬件支持的倍率按钮、捏合变焦、点按焦点框与长按锁定。
- 后置闪光灯关闭/自动/开启，照片保存方向正确，前置预览镜像、保存照片采用非镜像。
- 手机横持拍照：保存结果方向正确（应用操作界面保持竖向）。
- 3/10 秒定时可拍照；倒计时期间退后台后不继续触发旧拍摄。
- 网格、曝光补偿可生效；拒绝相机权限后可从设置授权再重试。
- 视频首次请求麦克风，开始/停止录像、计时、保存及本次播放可用。
- 录像中退后台：停止录像并保存，返回后同一相册可查看该视频。

## 保存与编辑

- 照片权限拒绝时有明确提示，内容保留为待保存状态，没有假报「已保存」。
- 从应用设置授予权限后回来，待保存原文件可重试，但上一会话内容不重新展示。
- 杀死并重开进程，本次相册为空；未保存内容后台重试。
- 编辑曝光/对比度/饱和度/黑白、裁剪比例及位置和旋转；完成后应用预览与系统照片一致。
- 编辑取消不改变原记录，保存失败保留原图，权限不足时有明确反馈。
- 移出本次预览只改变借拍相册，系统照片仍保留原记录。

## 引导式访问与自动化

- 设置好系统引导式访问及密码 / Face ID，手动开始；相机右上角变为黄色实心锁，点按确认「引导式访问已开启」。
- 引导式访问中无法退出借拍，但可以拍照、查看本次相册和修改本次照片。
- 按系统说明用机主身份结束；应用状态更新为未锁定。
- 完成全部首次权限授权后配置快捷指令：借拍被打开 → 开始引导式访问 → 立即运行。
- 重开借拍确认自动启动；失败时可手动启动，应用不能误报「已锁定」。
- 实测一次结束/恢复流程再交给别人使用。

## iOS 18 界面与操作

- 默认 16:9 照片模式与参考一致，模式和快门覆盖取景画面；可在比例控制切换 4:3 / 16:9 / 1:1，系统照片的实际尺寸比例与预览一致。
- 左右滑动或点文字切换照片/视频；选中项与快门中心对齐，照片快门白色、视频快门红色。
- 点曝光选项可左右拖动刻度尺，双击恢复默认；定时选项可选关闭、3 秒、10 秒。
- 左下角进入浅色全屏本次照片页；胶片条与左右翻页同步选择，点按照片隐藏/显示工具栏。
- 顶部「照片」及左下角网格按钮只显示本次内容；网格点选回到对应照片。
- 点心形图标收藏，系统照片的同一条记录收藏状态改变；旧图不被访问或修改。
- 双击/捏合缩放照片，缩放后单指拖动查看细节，缩小后可继续翻页。
- 点右下角调整图标进入全屏编辑，调整/滤镜/裁剪互相切换；取消退出、完成保存。
- 裁剪模式选择比例后拖动照片调整取景，旋转按钮和还原按钮可用。
- 小屏 iPhone 无控件重叠；顶部图标避开刘海，底部按钮避开主屏指示条。

## 普通版与可选诊断

- 普通 IPA 的编辑小组件面板只有样式、点击行为、来源、周期、独立编号，无“照片排查”；二进制没有诊断采样器与测试图字符串。
- 显式诊断构建仍能执行绘制、相册读取和图片请求三个阶段，默认关闭。两种编译模式都运行 PhotoKit 源码宿主检查。
- 应用切换器只显示黑色遮罩，照片页与首次启动没有“本次拍摄说明”等长篇介绍；权限和保存错误仍有提示。

## 系统建议取景与照片跳转（0.3.4）

- 用已被系统照片分析、主体在边缘的横图和竖图，核对小 / 中 / 大组件保留原有放大程度，仅移动取景位置。系统没有有效建议时应继续显示清晰居中图。
- 同一张照片系统推荐位置变化后，缓存应区分裁剪位置；重新添加仍取得高清图片。
- 点击行为有三个选项，默认不打开应用；明确选“在系统照片中打开”时，检查最终大图确为当前显示的照片，分别测试借拍冷启动和后台恢复。
- 照片不可访问或已隐藏时，跳转应提示错误，不改开别的图片；非照片样式和占位页不使用旧照片链接。
- 引导式访问锁定及自动开启它的快捷指令可能阻止系统照片跳转，单独核对未锁定状态。
