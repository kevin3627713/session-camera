# 隐私与会话设计

## 信任边界

应用内相册仅由本次相机回调产生，不由系统照片查询产生。应用进程会话的 UUID、拍摄 ticket、资产 ID 与图库列表仅存在于内存中，由 AppDelegate 持有 SessionStore。切换应用、锁屏、暂时 inactive 或视图重建均保留同一会话。只有应用进程重新启动时创建空会话；系统在后台终止进程也属于重新启动。

`SessionLedger` 是正式应用和测试包共同使用的同一个源文件。拍摄前发放 ticket，拍摄完成及编辑完成时再次检查。晚到的上一轮照片/视频允许继续保存到系统照片，但不能加入新相册。后台时仅停用倒计时和相机，不关闭画廊或编辑页，晚到的本轮拍摄回调继续加入同一会话。启动文件清理只执行一次，避免视图重建误删当前照片。

任务切换器遮罩由 AppDelegate 在 willResignActive 同步添加，遮住相机、照片、编辑及视频内容；恢复活动时移除。

## PhotoKit 读写

由于需要修改系统照片中的同一条记录，申请 `.readWrite`。推荐有限访问：Apple 明确说明应用新创建的资产会自动加入该应用的有限访问范围：[WWDC20](https://developer.apple.com/videos/play/wwdc2020/10641/)。

Photos 读取只用于编辑和收藏，均通过 PHAsset.fetchAssets(withLocalIdentifiers:) 请求当前资产 ID。ID 来自创建本次资产的 placeholder，仅由 SessionStore 在当前 ticket 合法且该条本次照片仍存在时传入。编辑使用 requestContentEditingInput / PHContentEditingOutput / PHAdjustmentData / PHAssetChangeRequest；收藏只更新 isFavorite。读取和修改前后均检查当前会话。照片网格和胶片条完全来自当前内存列表，没有引入新的图库查询。

没有图库全量查询、相册枚举、按时间搜索、系统照片挑选器、有限访问管理 picker、导入旧照片入口、系统照片跳转、系统相册删除请求或照片分享入口。`PHPhotoLibraryPreventAutomaticLimitedAccessAlert` 阻止启动时自动展示有限相册管理界面。仅添加权限时只支持保存，编辑会明确报无法访问。系统仍可能要求用户确认每次修改。

非破坏性编辑保留原图，本应用本次会话中也保留本地原文件。所有新修改从本次原图和完整调整参数重新渲染，不累积有损编辑。恢复原图按钮将调整参数重置，保存后同步原始外观，系统照片仍可原生恢复。

## 临时文件和保存失败

拍摄原文件先写入 Application Support/SessionCamera，排除设备备份，使用文件保护，然后写入 Photos。未完成写入 Photos 的文件有 `.pending` 标记；成功后移除标记。已保存原图和编辑副本保留到下一次进程启动时清理；主动从预览移除也可清理对应已保存文件。未保存文件保留，以便应用回来或再次启动时重试。

恢复流程只处理待保存文件，绝不将旧文件重新注册到当前画廊。它不保存旧资产 ID，不构造上一轮相册。极少数情况下，系统 Photos 已提交成功但进程在移除 pending 标记前崩溃，下一次重试可能产生重复记录；没有查询整个图库来实现崩溃场景的跨进程去重。

系统照片/iCloud Photos 使用手机自身配置同步；本应用没有额外上传、定位、跟踪、统计或远程服务。照片权限被撤销或空间不足时，会提示失败并保留本地待保存原文件。卸载应用会删除仍未保存的本地文件。

## 设备锁定

应用内相册隔离始终生效。若对方能退出应用，则仍可能自行进入其他应用。因此借出整部手机前，使用系统引导式访问。

普通个人 iPhone 上程序化开启引导式访问受 iOS 限制，`requestGuidedAccessSession` 仅用于获 MDM 授权的受监督设备。代码不声称绕过此限制。可以手动连按三下侧边按钮开始，或由机主在快捷指令里配置「借拍被打开 → 开始引导式访问 → 立即运行」。应用只检测和显示系统的实际状态。

## 可选照片小组件（0.3.3 实验分支）

上文关于不枚举图库的说明指相机及本次照片预览。新增随机照片小组件在独立扩展进程中，按用户在原生编辑面板选择的相册、文件夹或授权照片读取资产。文件夹递归读取子相册，去重并排除隐藏照片和视频；这些数据不会进入 SessionStore 或 SessionGallery。

每个小组件自己保存来源、周期和独立编号，默认点按不打开应用。具名相册 / 文件夹需要完整照片访问，有限权限仅支持已授权照片。主应用的权限管理入口使用机主身份验证，不展示图库；小组件按所选来源在主屏幕显示照片。没有额外 App Groups 或图库共享文件，网络图片请求仅由系统 PhotoKit / iCloud 处理。见 [配置说明](CONFIGURABLE_WIDGETS.md)。

0.3.1 在扩展自己的 Caches 目录缓存用于展示的高清裁剪 JPEG，最长边 1200 像素，最多 32 个文件 / 24 MiB，使用首次解锁后的文件保护。缓存按资产 ID、修改时间和图片尺寸索引，不保存全局当前随机照片，不进入相机本次列表。读取前必须确认照片权限有效且该资产当前仍可访问；资产删除或失去访问权限时不使用残留缓存。系统可以清理缓存，卸载应用也会清除。小组件移除本身不代表清除扩展缓存。

0.3.3 保留 0.3.2 每次只准备当前一张高清图片的策略。诊断枚举、测试图、分阶段诊断页面、系统日志与内存采样移到 native/WidgetDiagnostics，默认不编译。普通 IPA 没有“照片排查”配置项或这些日志。只有显式启用 WIDGET_PHOTO_DIAGNOSTICS 的诊断构建才包含它们，仍不记录资产 ID、相册名称或照片内容，不上传数据。
