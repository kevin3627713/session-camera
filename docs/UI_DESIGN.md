# iOS 18 界面设计

本次界面对齐 iOS 18 的原生相机和照片编辑的布局、黑色底色、SF Symbols、字号层次和黄色选中态。完整的系统相机不是可嵌入组件；这里使用 AVFoundation、SwiftUI 与 UIKit 实现应用自己的界面。

## 相机

| 区域 | 布局与交互 |
| --- | --- |
| 顶部 | 避开设备安全区域，44 pt 控制行；左侧闪光灯，中间展开箭头，右侧隐私/引导式访问 |
| 取景 | 照片保持 3:4，长屏按宽度铺满，小屏等比缩小；展开选项只替换模式行，取景区域固定 |
| 倍率 | 未选中圆形按钮 32 pt，选中 42 pt，黄色数字和小号 ×；根据硬件显示可用镜头 |
| 模式 | 48 pt 高度；当前「照片」或「视频」对齐快门中心，切换带平移动画，可左右滑动 |
| 快门 | 76 pt 白色外环、64 pt 内圆；照片白色、视频红色，录像时方形停止键 |
| 底部 | 左侧 50 pt 本次缩略图，右侧 50 pt 前后摄像头；为主屏指示条预留空间 |
| 选项 | 圆形闪光灯、曝光、定时、网格；点选后显示单项控制，曝光采用居中的刻度尺 |

所有主要触控目标至少 44 pt；倍率虽有小圆形视觉，实际触控区域为 44 × 44 pt。模式切换和倍率切换在拍照、倒计时或录像中受限。

## 照片与编辑

照片页全屏打开，黑底、顶部日期/时间和返回箭头、紧凑胶片条，底部使用蓝色图标。单击隐藏/显示工具栏，双击缩放，捏合缩放和左右翻页保持原有实现。成功保存不再占用一整行文字；保存中或失败时仍明确反馈。

编辑页全屏打开，将控制分成「调整 / 滤镜 / 裁剪」。调整时只显示当前参数、图标和刻度尺；滤镜提供原片与单色预览；裁剪显示九宫格和四角边框，可旋转、选择比例和拖动照片确定取景。取消与完成放在底部两侧。保留曝光、对比度、饱和度、旋转、裁剪、黑白和还原的原有渲染/保存路径。

## 产品约束

右上角锁图标取代系统相机的 Live Photo 图标。黄色实心锁只在系统报告引导式访问已开启时显示。首次使用说明与主动选择的提醒保留，其余时候不会默认弹出说明页。

没有增加未实现的 Live Photo、人像、夜景或其他拍摄模式按钮。照片页的眼睛斜线表示「移出本次预览」，不冒充删除系统照片。没有跳转系统照片、导入旧图或系统相册浏览入口。

## 可复现的视觉检查

[界面检查工作流](../.github/workflows/ui-preview.yml) 在 macOS runner 上，使用实际的相机、照片页、编辑页 Swift 源码编译一个独立 iOS 模拟器程序，截图正常屏和小屏的六种状态：相机、曝光控制、视频、照片、调整编辑、裁剪。

测试照片由 native/UIPreview/PreviewApp.swift 原创程序绘制，只存在于独立预览构建。CAMERA_UI_PREVIEW 编译条件没有加入 Runner，发行 IPA 不包含这个演示入口。预览不请求系统照片和相机权限、不读真实照片，也不会验证真实相机画质或系统保存行为。

在 macOS 运行 **bash scripts/capture_ui_preview.sh**，输出在 artifacts/ui/，包含 PNG、编译日志、设备和系统版本清单。模拟器截图可用于检查位置、间距、字体、裁剪与小屏遮挡；真机拍摄和 PhotoKit 行为仍按 [验收清单](ACCEPTANCE.md) 检查。
