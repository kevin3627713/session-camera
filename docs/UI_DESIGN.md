# iOS 18 界面设计

本次界面以用户提供的 iOS 18 真机参考为主要依据：1170×2532 px（390×844 pt）、16:9 照片模式与浅色照片浏览。参考文件只在本地 assets 用于对照，已加入 Git 忽略规则。界面由 AVFoundation、SwiftUI 与 UIKit 实现。

## 相机

| 区域 | 布局与交互 |
| --- | --- |
| 顶部 | 按真机参考的顶栏高度定位；左侧圆形闪光灯/曝光，中间展开箭头，右侧隐私/引导式访问 |
| 取景 | 默认 16:9，画面延伸到模式与快门后面，带细角标；4:3 和正方形另有等比取景，输出比例同步 |
| 倍率 | 共用半透明胶囊底；未选中圆形按钮 32 pt，选中 42 pt，黄色数字和小号 ×；根据硬件显示镜头 |
| 模式 | 44 pt 高度；当前「照片」或「视频」对齐快门中心，切换带平移动画，可左右滑动 |
| 快门 | 72 pt 白色外环、60 pt 内圆；参考截图白色外环实际为 216 px / 3；照片白色、视频红色 |
| 底部 | 左侧 48 pt 本次缩略图，右侧 48 pt 纯箭头前后摄像头；控制区与底部留白对齐参考 |
| 选项 | 圆形闪光灯、曝光、定时、网格；点选后显示单项控制，曝光采用居中的刻度尺 |

相机的主要触控目标至少 44 pt；倍率虽有小圆形视觉，实际触控区域为 44 × 44 pt。模式切换和倍率切换在拍照、倒计时或录像中受限。

## 照片与编辑

照片页全屏打开，白底和系统状态栏、顶部日期/时间、圆形返回/更多、「照片」胶囊、叠在照片底部的紧凑胶片条。底部使用蓝色图标与浅灰圆形/胶囊背景，收藏、信息、编辑共用胶囊。本次网格入口只展示当前会话；收藏通过 PhotoKit 修改当前资产。单击隐藏/显示工具栏，双击/捏合缩放和翻页保留。成功保存不占一整行文字；保存中或失败仍明确反馈。

编辑页全屏打开，将控制分成「调整 / 滤镜 / 裁剪」。调整时只显示当前参数、图标和刻度尺；滤镜提供原片与单色预览；裁剪显示九宫格和四角边框，可旋转、选择比例和拖动照片确定取景。取消与完成放在底部两侧。保留曝光、对比度、饱和度、旋转、裁剪、黑白和还原的原有渲染/保存路径。

## 产品约束

右上角锁图标取代系统相机的 Live Photo 图标。黄色实心锁只在系统报告引导式访问已开启时显示。设置仅由锁图标主动打开，或由机主主动开启的提醒显示；首次启动不再自动弹出说明页。

没有增加未实现的 Live Photo、人像、夜景或其他拍摄模式按钮。照片页垃圾桶操作会先明确确认「移除预览」，系统照片仍然保留。「照片」替代参考中的「所有照片」，打开本次网格；左下角也是本次网格入口。没有跳转系统照片、导入旧图或系统相册浏览入口。

## 可复现的视觉检查

[界面检查工作流](../.github/workflows/ui-preview.yml) 在 macOS runner 上，使用实际相机、照片页、编辑页 Swift 源码编译独立模拟器程序，使用 iPhone 13 的 390×844 pt 参考尺寸和 iPhone SE 小屏，截图七种状态：相机、曝光控制、视频、照片、调整编辑、裁剪、本次网格。

测试照片由 native/UIPreview/PreviewApp.swift 原创程序绘制，只存在于独立预览构建。CAMERA_UI_PREVIEW 编译条件没有加入 Runner，发行 IPA 不包含这个演示入口。预览不请求系统照片和相机权限、不读真实照片，也不会验证真实相机画质或系统保存行为。

在 macOS 运行 **bash scripts/capture_ui_preview.sh**，输出在 artifacts/ui/，包含 PNG、编译日志、设备和系统版本清单。模拟器截图可用于检查位置、间距、字体、裁剪与小屏遮挡；真机拍摄和 PhotoKit 行为仍按 [验收清单](ACCEPTANCE.md) 检查。

截图脚本等待目标页面和图片渲染完成的标记，再留出界面动画完成时间；超时或不同页面生成重复截图都会使检查失败。[本次截图](screenshots) 来自 [运行 37194854719](https://github.com/kevin3627713/session-camera/actions/runs/37194854719)，来源提交、设备、运行地址和文件校验值记在 screenshots/manifest.json。
