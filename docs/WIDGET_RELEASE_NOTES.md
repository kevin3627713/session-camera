# 借拍 0.3.0：原生编辑小组件与独立随机相册

在原实验分支继续开发，仍使用同一个借拍主应用和同一个 WidgetKit 扩展。主程序 / 扩展均为版本 0.3.0、build 5。用原签名身份和包名映射覆盖更新，并保留 SessionWidgets.appex，不增加第四个主应用或新的扩展 App ID。

- 四个旧预设保留 kind，现在都可长按 → 编辑小组件，在原生翻转面板切换透明、空白、磨砂、普通背景、随机相册照片。
- 默认点击不打开应用，用完整区域的交互意图接收点击；设置中可选择打开借拍。
- 随机照片支持相册、递归文件夹、有限访问下的已授权照片；排除视频和隐藏照片，文件夹去重。
- 每个组件自己保存来源、独立编号、更换周期与点击行为。默认 60 分钟，可填写 5～10080 分钟，系统调度可能延后。复制配置时请选择一个新独立编号。
- 同周期重载保持照片，有多张图片时避免连续重复。压缩缩略图与请求时限控制扩展内存和 iCloud 等待。
- 新增需要机主身份验证的照片权限 / 刷新入口；相机本次预览与会话隔离逻辑保持原样。

选择具名相册或文件夹需要完整照片访问；有限权限只能选择已授权照片。照片会显示在主屏幕。磨砂现由实例内部系统 Material 绘制，以支持同一预设的不同实例同时使用不同样式。

上一版用户已确认 iOS 18.7.8 可正常使用。本版仍为实验预发布，原生编辑迁移、点击区域、材质显示和扩展真机权限 / 调度需要在手机上验收。
