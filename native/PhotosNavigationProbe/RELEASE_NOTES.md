# 照片跳转诊断 0.1.1 · 独立 App

新增“数据管理”：清空测试记录保留当前相册、照片和链接设置；重置全部诊断数据清空记录、目标和链接设置。清理同时写入本机存储，后续每轮无需重装；执行测试期间禁用清理。“只检查系统解析结果”加入诊断报告并标明未执行跳转。版本 0.1.1 / build 2，覆盖安装保留原签名身份可沿用已有选择与记录。

机主已确认 0.1.0 的 A / 中转普通派发可打开目标照片。C/D 的照片与相册 UUID 在 iOS 18.7.8 上被正确解析，但中转敏感派发均被系统拒绝（LSApplicationWorkspaceErrorDomain / 115）；未认定具体权限原因。下一轮测试外部相册入口 B / 方式 4，再只检查 H/I 的实际解析字段。

为未越狱 iOS 18.7.8 自签真机测试准备。选择真实相册及其中一张照片，导出本机标识、UUID 和经双向核对的完整云标识。提供 11 个链接预设、自定义 URL 编辑，以及普通打开、主应用私有普通 / 敏感派发、中转扩展私有普通 / 敏感派发五种方式。

尝试读取当前设备的 Photos URL 解析字段，记录派发成功 / 失败与系统错误；返回后手动记录实际页面。最近 30 次记录留在本机，可复制或分享完整报告。独立 Bundle ID，不包含借拍相机或桌面小组件，不创建测试照片。

安装：自签 `photos-navigation-probe-unsigned.ipa`，保留并签署内置 `PhotosNavigationShare.appex`。沿用同一签名身份覆盖安装；首次允许完整照片访问。升级后在“数据管理”中清空上一轮测试记录，继续使用已选目标。系统接受派发不等于在指定相册定位成功。

9 项标识与 URL 检查、iPhone 编译和 IPA 结构检查由 GitHub Actions 执行。指定相册跳转尚未真机验证，此发布是诊断工具，不表示功能已经实现。
