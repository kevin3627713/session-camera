# 照片跳转诊断 0.1.2 · 独立 App

机主已在未越狱 iOS 18.7.8 上确认：将预设 C 的 `photos://asset?uuid=…&albumuuid=…` 放入系统快捷指令，使用“URL → 打开 URL”，可在指定相册中打开目标照片，返回位置及相邻照片保留该相册。

新增“6 · 主应用：直接系统启动”和“7 · 中转扩展：直接系统启动”。使用系统 INCAppLaunchRequest / FrontBoard 启动真实 Photos 并携带完整链接，保持各自实际调用身份，记录原始 NSError、底层错误与主应用状态。先检查系统类和方法签名；不可用或超时会记录结果。第三方 App / 扩展的真机能力仍需测试。

本轮操作：

1. 保留原签名身份和 `PhotosNavigationShare.appex`，覆盖安装 0.1.2 / build 3；可沿用已有相册和照片。
2. 点“清空测试记录”，关闭“使用自定义 URL”，选择预设 C。
3. 先执行方式 6，返回后填写“实际页面”。
4. 对同一目标执行方式 7，填写结果。
5. 若打开照片，检查返回和相邻照片是否属于目标相册；最后点“复制完整诊断报告”。仅需这两次，无需重测旧组合。

保留清空记录、重置数据、11 个链接预设、解析检查与本机报告。独立 Bundle ID，不包含借拍相机或小组件；原有借拍生产点击行为尚未更改。报告留在本机，按复制 / 分享按钮导出。

GitHub Actions 执行 9 项标识与 URL 检查、iPhone 编译及 IPA 结构检查，核对两个可执行文件均包含新启动路径。快捷指令成功不等于新直接调用已通过真机验证。
